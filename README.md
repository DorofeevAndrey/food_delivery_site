## О проекте

Этот проект — учебный сервис доставки еды, который я разрабатываю для прокачки собственных навыков в веб‑разработке.

Цели проекта:

- **Backend**: практика FastAPI, SQLAlchemy, Alembic, интеграции с Postgres, Redis, MinIO (S3‑хранилище).
- **Frontend**: отработка Next.js, React, модульных CSS, построения дизайн‑системы (Atoms/Molecules/Organisms), работы с REST API.
- **Инфраструктура**: использование Docker и docker-compose для локальной разработки.

Функциональность на текущий момент:

- авторизация через Telegram и личный кабинет пользователя;
- профиль и уведомления;
- каталог продуктов с загрузкой изображений в S3‑совместимое хранилище (MinIO);
- корзина (в разработке) и подготовка к оформлению заказов.
